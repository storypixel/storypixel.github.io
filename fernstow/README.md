# Fernstow marketing page

Static page for https://iamnotsam.com/fernstow/. The iPhone app remains in the
separate Fernstow repository. This page is not a web app or live extraction tool.

Preview `index.html` directly or use the portfolio's existing Vite server at
`/fernstow/`. All content and imagery are local; fonts reuse `public/fonts/`.
Vite copies the folder unchanged into `dist/fernstow/` during the site build.

The example tabs are explicitly illustrative. Contact links open an email draft;
no email list, analytics, account system or submission endpoint is configured.
Photo provenance is in `assets/CREDITS.md`.

Before announcing availability, replace the development copy with a verified
App Store or TestFlight link and review all feature claims against the release.
The current page does not promise comment ingestion, saved-collection imports,
ratings, business hours, booking links, or cross-device sync.

Publishing: this site's master push triggers its existing GitHub Pages workflow.
Do not push without Sam's explicit approval. Do not edit unrelated portfolio
routes or the Utter documents to publish this folder.
